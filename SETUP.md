# SmartOverlay AI — запуск и подключение GPT-4o Vision

## 1. Получить API-ключ OpenAI

1. Откройте https://platform.openai.com/signup и зарегистрируйтесь (или войдите, если аккаунт уже есть). Регистрация бесплатная, аккаунт OpenAI ≠ ChatGPT Plus — для API нужен именно платформенный аккаунт.

2. Пополните баланс. OpenAI с лета 2024 года требует предоплату — пополнение от $5. Откройте https://platform.openai.com/settings/organization/billing/overview, нажмите **Add to credit balance**, привяжите карту и положите $5–$10 для старта. С российскими картами не работает — нужна иностранная карта или Wise/Revolut/Capitalist/виртуальная карта от посредника.

3. Создайте ключ. Откройте https://platform.openai.com/api-keys, нажмите **Create new secret key**. Имя — любое (например, `smartoverlay`). Permissions можно оставить **All** или ограничить до **Restricted → Model capabilities → Read**. Скопируйте ключ — он начинается на `sk-…` или `sk-proj-…`. **Ключ показывается ровно один раз**, потом доступен только хвост — храните его в надёжном месте.

4. Опционально: на https://platform.openai.com/settings/organization/limits задайте **Monthly budget** (например $5), чтобы случайно не уйти в перерасход.

### Сколько это будет стоить

GPT-4o Vision с `detail=low` (мы используем именно его) стоит $2.50 за 1 млн input-токенов. Один скриншот = 85 input-токенов изображения + ~80 токенов системного промпта + ~150 токенов ответа. Грубо **~$0.0008 за анализ**. При интервале 4 секунды это ≈$0.7 за час непрерывной работы — поэтому в Настройках по умолчанию интервал 4 сек, но можно увеличить до 30, либо включать Pause (`Ctrl+Alt+P`), когда не нужно.

## 2. Запуск проекта

Требования: Windows 10/11, Node.js 20+, Rust 1.70+ с MSVC, Python 3.11+ (у вас 3.14 — тоже подходит).

### Backend

```powershell
cd C:\Projects\smartoverlay-v2\backend
.\venv\Scripts\activate
pip install -r requirements.txt   # подтянет openai и httpx, если ещё не стоят
uvicorn app.main:app --host 127.0.0.1 --port 18321 --reload
```

При первом запуске после обновления база `data/smartoverlay.db` сама добавит новые колонки `openai_api_key`/`openai_model` в таблицу `users` (миграция в `app/database.py`). Удалять БД не нужно. Если что — её можно безопасно стереть, она пересоздастся с дефолтами.

Проверка, что backend жив:

```powershell
curl http://127.0.0.1:18321/health
```

Ответ должен быть `{"status":"ok","version":"0.1.0","vision_provider":"gpt4o"}`.

### Frontend + Tauri

Во **втором** терминале:

```powershell
cd C:\Projects\smartoverlay-v2
npm install                # если ещё не стояло
npm run tauri dev
```

Соберётся Rust-часть (первый раз медленно — 3–5 минут на компиляцию зависимостей), запустится Vite на `localhost:1420`, откроется два окна:

- **Overlay** — прозрачный, всегда поверх, в левом верхнем углу. Click-through включён по умолчанию (клики проходят насквозь). Когда наводите мышку на верхнюю шапку — она «оживает», и можно нажимать кнопки.
- **Dashboard** — скрыт, открывается из системного трея или хоткеем `Ctrl+Alt+D`.

### Хоткеи

| Комбинация | Действие |
|---|---|
| `Ctrl+Alt+S` | Анализировать экран немедленно |
| `Ctrl+Alt+D` | Открыть/скрыть Dashboard |
| `Ctrl+Alt+P` | Пауза / возобновить |

## 3. Вставить ключ в приложение

Откройте Dashboard (`Ctrl+Alt+D`) → **Настройки**.

В секции **AI Vision провайдер** уже выбрана карточка **GPT-4o** (помечена «рекомендуется»). Ниже появится секция **API ключ OpenAI** с предупреждением «⚠ Ключ не настроен».

В поле введите свой ключ (`sk-…`), нажмите **Сохранить**. Ключ сохранится в SQLite базе backend (`backend/data/smartoverlay.db`, столбец `users.openai_api_key`). На фронт он обратно никогда не приходит — отдаётся только маскированное превью вида `sk-pro…X9aB`.

Нажмите **Проверить провайдер**. Если всё в порядке, появится зелёный баннер `✓ gpt4o работает — …`. Если красный — там будет текст ошибки от OpenAI (чаще всего: `Insufficient credit` — пополните баланс; `Invalid API key` — перепроверьте ключ).

После этого нажмите `Ctrl+Alt+S` поверх любого экрана — overlay покажет реальное распознавание контента.

### Альтернатива: ключ через `.env`

Если не хотите хранить ключ в БД, отредактируйте `backend/.env`:

```env
OPENAI_API_KEY=sk-ваш-ключ
VISION_PROVIDER=gpt4o
```

Перезапустите backend. Ключ из БД имеет приоритет над `.env`, поэтому если вы уже сохраняли его через UI, сначала нажмите «заменить» и оставьте поле пустым (тогда сработает значение из `.env`).

## 4. Если что-то не работает

**Overlay видно, но он не реагирует на клики.** Это нормально — click-through включён по умолчанию, чтобы не мешать играм/работе. Наведите мышку на шапку с кнопками — там click-through временно отключается.

**Хоткеи не срабатывают.** Какое-то другое приложение перехватило `Ctrl+Alt+S` (часто это софт от GeForce Experience, Discord, Snipping Tool). Закройте конфликтующую программу или поменяйте хоткей в `src-tauri/src/lib.rs` (функция `setup_shortcuts`).

**В overlay показывается «API ключ OpenAI не настроен».** Откройте Dashboard → Настройки → API ключ → введите и сохраните. Если уже сохраняли — нажмите «Проверить провайдер», ошибка покажет в чём дело.

**Пишет «429 Insufficient credit».** Пополните баланс на https://platform.openai.com/settings/organization/billing.

**Пишет «401 Invalid API key».** Ключ неверный или удалён. Создайте новый на https://platform.openai.com/api-keys и обновите его в Настройках.

**Backend крашится при старте.** Скорее всего, БД старая. Остановите backend, удалите `backend/data/smartoverlay.db`, запустите заново — БД пересоздастся с актуальной схемой.

**Не собирается Rust.** Установите MSVC Build Tools и WebView2 — гайд https://tauri.app/start/prerequisites/.
